# Kho Tài liệu & Code Mẫu (Examples & References)

> [!TIP]
> Đây là nơi lưu trữ các file cấu trúc, YAML, Dockerfile, Bash script chuẩn mực để các bạn tham khảo khi gặp khó khăn. Khuyến khích các bạn tự gõ lại (type) thay vì copy/paste để nhanh nhớ lệnh hơn!

Danh sách các tài liệu tham khảo được gom lại từ các tuần:

- **hello.sh**: Cấu trúc cơ bản của một Bash Script.
- **Dockerfile**: Cấu trúc chuẩn để build một container image từ multi-stage.
- **docker-compose.yml**: Cấu trúc để định nghĩa ứng dụng chạy bằng Docker Compose.
- **deployment.yaml** / **service.yaml**: Các object cơ bản trong Kubernetes.
- **.gitlab-ci.yml**: Cấu trúc đường ống CI/CD trên GitLab.
- **argocd-app.yaml**: Định nghĩa Application theo chuẩn GitOps cho ArgoCD.
- **pipeline-architecture.md**: Thiết kế kiến trúc tổng thể luồng CI/CD.
- **template-bao-cao.md**: Form mẫu chuẩn để viết báo cáo tiến độ/công việc.
